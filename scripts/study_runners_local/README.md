# Local Study Runner Scripts

This folder keeps the original orchestration scripts used during the thesis experiments. They are preserved for traceability, but they are not the portable public interface of UniBench.

These scripts may contain historical Windows/WSL paths, local conda environment names, and references to external method repositories or full generated-output trees that are not included in this release. Before reuse, replace those paths with local equivalents and verify the expected directory structure.

For portable benchmark assets, use:

- `data/manifests`
- `data/prompts`
- `data/reference_models`
- `scripts/unibench`
- `scripts/benchmark`
- `results/raw_metrics`
- `results/summaries`
